### 💡 작성할 때 주의할 점
1. `<details>`와 `<summary>` 태그는 평소에는 내용을 접어두고, 클릭했을 때만 아래로 펼쳐주는 HTML 내장 기능입니다.
2. Docsify의 자동 복사 플러그인은 마크다운의 **코드 블록(키보드 1번 왼쪽의 백틱 ```` ``` ```` 세 개로 감싸는 구역)**에 마우스를 올렸을 때 우측 상단에 **`Copy`** 버튼을 자동으로 띄워줍니다.
3. 따라서 `<details>` 태그 내부에 코드 블록(```text ... ```)을 넣어두면, **평소에는 숨겨져 있다가 ➡️ 클릭해서 열면 ➡️ 마우스를 올렸을 때 복사 버튼이 짠! 하고 나타나는 구조**가 완벽하게 완성됩니다.

### 🔄 저장 후 확인하기
1. `week1/day1.md`로 파일을 저장(Commit)합니다.
2. `_sidebar.md` 목차에 `[1일차: 개발 환경 세팅](week1/day1.md)` 링크가 잘 연결되어 있는지 확인합니다.
3. 약 30초 뒤 내 웹사이트 주소로 접속해서 해당 메뉴를 클릭해 보세요. 토글이 부드럽게 열리고 마우스를 올렸을 때 우측 상단에 **`Copy`** 문구가 뜨며 복사가 잘 된다면 성공입니다!

직접 테스트해 보시면서 **토글 디자인이 생각보다 밋밋해서 노션처럼 더 예쁘게 꾸미고 싶거나**, 혹은 **복사 버튼의 문구를 'Copy' 대신 한글인 '복사하기'로 바꾸고 싶은 부분**이 있으신가요? 편하게 말씀해 주시면 바로 수정법을 안내해 드릴게요.
